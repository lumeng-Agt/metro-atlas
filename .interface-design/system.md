## 色彩与排版

浅灰真实地图配深蓝灰工具面板。界面底色#111923、面板#19232F、控件#222F3D、正文#ECF1F7、辅助#AAB8C7、边线#344353、强调#4BC5B0、强调悬停#73D6C4、强调底上的文字#102B2B。主要确认按钮使用强调底与深色文字；取消/查看使用中性底。当前状态同时用文案和线型表达。

UI 代码只引用 `ui_theme.gd` 的语义常量（CANVAS / SURFACE / SURFACE_ALT / INK / MUTED / ACCENT / ACCENT_HOVER / ON_ACCENT / BORDER / BORDER_STRONG / INK_ON_LIGHT 等），不重复书写色值。地图渲染按下一段独立处理。

**浅色浮层（已批准的第二套配色）**：教学浮层 `tutorial_spotlight.gd` 与导出用的示意图、分享卡使用浅底深字，因为需要从深色地图上跳出来。面板#FFFEFA、边线#B7CEC2、文字#24332F、强调#24745E；深色页面上承载浅底内容的文字改用 `INK_ON_LIGHT`(#223745)。这套配色只用于浮层与导出图，不进入工作台主体；新增浅底界面须在此登记后才可使用。

地图独立使用 `map_style.gd`：灰白道路加描边、主路浅黄、水域蓝、公园绿、建筑灰蓝。细水线不压过道路。轨道实线、近似走廊蓝色虚线、示意灰色虚线、旧方案低强调虚线。

思源黑体500正文/700标题；正文18px、辅助16px（下限15px）、分组20px、对象标题24px、菜单标题44px。字号与44px控件基准只应用一次全局缩放。以4px为间距单位；6—8px圆角（弹窗10px、窗口12px、滑块轨道与光标2px、导出页脚等贴边容器0），细边线，无装饰渐变。

字号档位来自 `label(text, pixels)` 的第二个参数，全项目共 154 处；新增字号须落入上表档位，不另设孤立值。16px 是仅次于 15px 的高频档（38 处），承载菜单副标题、城市摘要、提案目标、存档错误提示与章节变化说明，与 15px 的差别在于它用于成句说明而非短标签。

## 组件与页面

顶部保留城市/年代/方案状态、撤销、保存、存档和菜单；故事/时间轴/资料在左栏页签。底部居中车站/铺轨；历史重组才显示线路整理。右侧上方对象标题，中间滚动属性，底部固定确认/取消/删除。

主菜单限宽，主要入口为继续、选城、存档；城市与教学选择放进独立新故事页。故事旁注位于可用地图内，可关闭和重读。存档行信息与操作分行；设置和资料长内容滚动。

窄窗口左右抽屉互斥；高缩放优先收起次要参数，地图高度≥360物理像素。工具栏按实际容器宽度换行，图层和署名不侵入操作区。操作教程只指向真实控件。

默认/悬停/按下/焦点/禁用/错误统一由主题管理。错误常驻草稿，取消清除；输入框保留文字撤销。地图参考缺失、存档错误、未知版本均显示可处理的原因。

## 本轮评审

代表页为上海1993建设工作台；保留实际渲染灰度结构和正常画面。第一轮修正：工具栏竖排、细水线过强、菜单过宽。第二轮检查：确认区、教学与故事遮挡、不同缩放。实际鼠标与自动布局结果分别记录于测试记录。

### 0.28 评审（2026-11-09）

方法：Godot 4.7.2 实际渲染 1600×980，像素色分布统计 + WCAG 对比度计算 + 令牌采用率统计。完整记录见 `docs/ui-review-0.28.md`。

结论：配色系统本身健康，声明的全部配色对对比度达标（正文 15.58、辅助 8.75、强调 7.49，全部高于 4.5）。真正的问题是令牌采用率——17 个语义 token 此前全项目只被引用 2 处。

本轮修正：UI 层硬编码色收敛到语义 token（`#111923` 6 处、`#223745` 3 处改为 CANVAS / INK_ON_LIGHT）；新增 ACCENT_HOVER、ON_ACCENT、INK_ON_LIGHT 三个 token；署名链接字号 12px 提到 15px，符合辅助字下限；浅色浮层配色登记为本文件已批准的第二套配色。

待办：无。上一版记录的「20px 分组字与 44px 菜单标题未实际使用」为误判——当时只统计了 `add_theme_font_size_override`，漏掉 `label()` 主入口；实测 20px 17 处、44px 1 处，均在用，该条已撤销。

### 0.28 档位收敛（2026-11-09）

按「承认真实档位、只收孤立值」处理：16px 补入正式档位表；地图提示 17px→18px，选城页标题 30px→24px，城市背景弹窗间距 10px→12px（回到 4px 网格）。全项目字号档位收敛为 15/16/18/20/24/44 六档，间距常量收敛为 0/12/16。

### 0.29 去圆角方框（2026-11-10）

按 `ui-design-workflow.md` 七步流程重做。问题是「每个信息块都套一个圆角方框」：面板圆角12+阴影、卡片圆角8+边框、按钮圆角8、标签页圆角8，四层圆角叠加。

参考：Mini Metro（无边框、无圆角、靠位置和留白分组）+ Linear（elevation 层级靠背景明度差，靠分隔线不靠卡片）。

**规则变更：**

- 面板改为**贴边直角色块**，去掉圆角与阴影，只用一根 1px 分隔线（`floating_box`：radius 0，仅 `border_width_right=1`）
- 面板内分组去掉卡片容器，改用 `card_panel()` 插入 `HSeparator` + 间距（`floating_card_box` 改为全透明零边距）
- 圆角统一收敛为 **0 / 3 / 4 / 6** 四档：贴边容器 0、选中项 3、控件 4、弹窗与窗口 6
- 面板贴左/右边缘（position 0），不再留 16px 浮动间距

**层级来源**：背景明度差（面板 #FFFFFF / 地图 #DFE4EA）+ 分隔线 + 字重，不再依赖圆角、边框、阴影三层叠加。

**实测**：面板 x=0 起、x=239 为分隔线、x=250 起为地图；解析 0 错误。

### 0.30 工程图纸方向（2026-11-10）

按 Interface Design 的领域探索重定方向：**像一张正在绘制的工程图纸**。

**Domain**：工程图纸、站台剖面、1992 深圳特区、考证档案、地铁拓扑图。
**Color world**：硫酸纸米白、制图墨黑、铅笔灰、坐标纸网格、老站牌绿、校对朱红。
**Signature**：历史对照条（你的选择 vs 历史实际，朱红标差异）—— 产品核心，尚未实现。
**Rejecting**：固定侧栏→地图全屏；卡片网格→分隔线；顶部标签页→底部进度；圆角阴影→直角单线。

**布局变更**：
