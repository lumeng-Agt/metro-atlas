造一座地铁 · Windows 免安装版 0.13.5

解压后双击“造一座地铁.exe”即可启动。无需浏览器、Node.js、Godot 安装或本地服务。五城简化矢量地图随程序一起提供，不需要地图账号或网络；地图数据范围外仍可规划，使用网格和游戏对象显示。

第一次规划：
1. 选择城市，再选“从零规划”或“扩建现实路网”。从零规划默认暂停，并提供一组街区出行需求。
2. 依次完成：放置车站 → 铺设物理轨道 → 创建运营线路。
3. 车站自带双向站台轨道。选择“直线铺轨”或“曲线铺轨”，从车站 A／B 端点起步，确认后才加入轨网。
4. 选择“创建运营线路”，按停站顺序点击已经接轨的车站，再确认线路。右侧线路详情可检查并开通。
5. 播放后查看候车、乘车和实际到达情况。需求、客流与运行参数是游戏模拟，不是现实预测。

常用操作：
- 拖空地图平移，滚轮缩放；选择模式可查看站点、轨道和需求详情。
- 车站草稿可拖动，按 R 旋转；点击站体内部即可选中。详情面板可改名、换车型、调整地下深度、从 A／B 端铺轨和删除。移站、转向、调深度和车型时会预览关联轨道，检查站体碰撞、坡度、交叉和站端顺接。
- 曲线铺轨依次点起点、弯曲控制位置和终点；接入既有轨道中段会先预览拆分。
- 深度范围 5—60 米，每次调整 5 米。坡度超过 35‰ 会阻止确认；300 米曲线半径是提示值。以上属于游戏预设。
- “连续铺设”可从自由端点继续；“结束铺轨”会退出工具，已确认区间不会被取消。
- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；Esc 先取消当前预览。空格暂停或继续。
- 顶部提供暂停和 1×／3×／10×速度。设置中可选四档界面缩放。
- 左侧可切换“线路、任务、统计”；统计页直接查看等候、在途、完成、放弃和中断人数。
- 底部固定提供车站、轨道、运营线路三个主要建设入口；模拟推进会标记存档为“未保存”，可手动保存或稍后自动保存。
- 退出、回菜单或切换城市前会检查保存结果。保存失败时可重试、另存 JSON、明确放弃未保存修改或取消并留在游戏；损坏存档不会被空白开局自动覆盖。若主存档损坏，会先尝试恢复有效备份，并在载入前保留独立恢复副本。
- 创建运营线路时可回看任意相邻停站区间并切换可用轨道走向；缩小时靠得很近的 A／B 接轨端会提供单独选择。
- 使用中的轨道被拆除后，线路会暂停并保留待修复区间。在线路详情选择“修复”，确认重新铺设的走向，再检查并开通线路。

存档：
格式 13 的本地存档位于 %APPDATA%\MetroAtlas\saves，最近进度在 %APPDATA%\MetroAtlas\last_game.json。读取旧版时会另存原始备份；版本 12 的操作历史和模拟时间会迁移。旧网页存档请先从网页端导出 JSON，再由本程序导入。
