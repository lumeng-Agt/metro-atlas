造一座地铁 · Windows 免安装版

开始：解压后双击“造一座地铁.exe”。不需要浏览器、Node.js 或安装 Godot。

快速操作：
1. 选择城市和“从零规划”或“扩建现实路网”；新开局默认暂停。
2. 首次从零规划会定位到一组街区出行需求，只显示 A 起点与 B 终点。橙色虚线表示出行方向，不是建议轨道。
3. 点“开始规划”，按提示在 A、B 附近各建一站，再连接两站端点、检查并开通线路。
4. 按播放观察这组需求的模拟服务结果。引导可跳过、查看全城、返回任务位置，也可以以后从左侧重玩。
5. 拖动地图平移，滚轮缩放。地图缓存尚未加载时，需求点仍按真实地理坐标显示；网格只是定位参考。

选择：点车站、轨道或需求地点看详情；选中车站后拖动可移动，右侧详情可改名、旋转或删除。
接轨：也可从车站详情点“从本站接轨”；端点会显示 A／B 并高亮。
调曲线：点轨道选中区间后拖动蓝色控制点。
拆除：点“拆除”后点车站或轨道；删除车站时关联区间会一并删除。
撤销／重做：Ctrl+Z／Ctrl+Y（或 Ctrl+Shift+Z）；Esc 取消当前操作；空格暂停。
界面缩放：主菜单“设置”中选择 100%、125%、150% 或 175%；地图缩放独立。
开局菜单已改为居中双栏布局，正文、菜单和建设按钮同步放大。1440 像素以下窗口会自动收起侧栏，可从顶部“线路／详情”按钮重新打开。
地图图层：地图右上角切换站体、需求和线路；顶部“线路／详情”按钮收起侧栏。

本机存档：%APPDATA%\MetroAtlas\saves；覆盖时保留 .bak 备份。
发行版本：Godot 4.7.2，Windows 64 位原生 2D。
