造一座地铁 · Windows 免安装版 0.16.1 · 存档格式 16

解压后双击“造一座地铁.exe”即可启动。无需浏览器、Node.js、Godot 安装或本地服务。五城简化矢量地图随程序一起提供，不需要地图账号或网络；地图数据范围外仍可规划，使用网格和游戏对象显示。

第一次规划：
1. 选择城市，再选“从零规划”或“扩建现实路网”。从零规划默认暂停，并提供一组街区出行需求。
2. 教学会逐次高亮真实的地图地点和下方工具栏按钮，并显示一句当前操作提示。按提示点击地图、车站、轨道与运营线路工具；完成当前操作后，焦点会移到下一处。教学不会代替玩家建设或确认。
3. 依次完成：放置车站 → 铺设物理轨道 → 创建运营线路。
4. 车站自带双向站台轨道。选择“直线铺轨”或“曲线铺轨”，从车站 A／B 端点起步，确认后才加入轨网。
5. 选择“创建运营线路”，按停站顺序点击已经接轨的车站，再确认线路。右侧线路详情可检查并开通。
6. 播放后查看候车、乘车和实际到达情况。需求、客流与运行参数是游戏模拟，不是现实预测。
7. 教学结束后，打开任务页继续周边扩建、重要目的地、换乘网络和高峰优化章节；也可创建分期建设阶段并指定要服务的出行。

城市发展事件按固定游戏日程预告并保存，每城包含住宅入住、就业增长及临时活动。客流变化幅度为游戏设定；结果比较会检查时间段和事件状态是否可比。

常用操作：
- 拖空地图平移，滚轮缩放；选择模式可查看站点、轨道和需求详情。
- 车站草稿可拖动，按 R 旋转；点击站体内部即可选中。详情面板可改名、换车型、调整地下深度、从 A／B 端铺轨和删除。移站、转向、调深度和车型时会预览关联轨道，检查站体碰撞、坡度、交叉和站端顺接。
- 曲线铺轨依次点起点、弯曲控制位置和终点；接入既有轨道中段会先预览拆分。
- 深度范围 5—60 米，每次调整 5 米。坡度超过 35‰ 会阻止确认；300 米曲线半径是提示值。以上属于游戏预设。
- “连续铺设”可从自由端点继续；“结束铺轨”会退出工具，已确认区间不会被取消。
- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；Esc 先取消当前预览。空格暂停或继续。
- 顶部集中城市、时间、暂停速度、撤销／重做与保存状态。设置中可选四档界面缩放或关闭短暂淡入动效。
- 左侧可切换“线路、任务、统计”；统计页直接查看等候、在途、完成、放弃和中断人数。
- 空白城市可选择街区挑战，目标与自由规划共用一份网络；可随时退出挑战继续扩建。
- 线路支持全天统一或分时段班距：早高峰 07:00—10:00、晚高峰 16:00—19:00，其余为平峰；更改不重排已发出的列车。
- 地图可切换规划、需求、可达性和运营问题分析；15分钟统计和抽样实际旅程记录可在统计页查看。
- 可展开规划复杂度信息查看里程、最深深度、曲线区间和换乘站数量。这些是游戏内比较数据，不是工程评分。
- 底部提供选择、车站、轨道、运营线路和更多工具；直／曲线、深度、连续铺设和候选走向显示在右侧建设详情。
- 主菜单和游戏内统一使用“存档中心”，按自动或命名存档分页；命名存档可保留独立进度。模拟推进会标记存档为“未保存”，可即时保存或稍后自动保存。
- 退出、回菜单或切换城市前会检查保存结果。保存失败时可重试、另存 JSON、明确放弃未保存修改或取消并留在游戏；损坏存档不会被空白开局自动覆盖。若主存档损坏，会先尝试恢复有效备份，并在载入前保留独立恢复副本。
- 创建运营线路时可回看任意相邻停站区间并切换可用轨道走向；缩小时靠得很近的 A／B 接轨端会提供单独选择。
- 使用中的轨道被拆除后，线路会暂停并保留待修复区间。在线路详情选择“修复”，确认重新铺设的走向，再检查并开通线路。
- 线路详情可从起点或终点继续扩建；原站序和有向走向保留，确认新增停站后线路暂停，检查并重新开通后恢复服务。
- 车站详情显示未接轨、已接轨未运营、运营中或待修复状态。统计页新增近一小时线路方向载客率、峰值载客和空载区间比例；没有足够班次样本时会明确提示。

存档：
格式 16 的本地存档位于 %APPDATA%\MetroAtlas\saves，最近进度在 %APPDATA%\MetroAtlas\last_game.json。版本 15 迁移前会保留独立原始备份；规划、时钟、活动列车、乘客及已完成出行保留，线路运力统计从迁移后开始累积。自动存档历史按城市和开局分别保留最近三份有效进度。命名存档支持搜索、改名、覆盖与删除。旧网页存档请先从网页端导出 JSON，再由本程序导入。
