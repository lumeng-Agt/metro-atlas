造一座地铁 · Windows 免安装版 0.17.0 · 存档格式 17

解压后双击“造一座地铁.exe”启动。无需浏览器、Node.js、Godot安装或联网地图服务。

这是城市历史复现的首批可玩样板，不是五城完整历史版。开始新游戏后选择城市，进入该城已有的历史章节，并按下方车站、轨道、运营线路工具亲手建设。逐城覆盖范围和未完成资料见压缩包内 docs/campaign-content-audit.md。缺少可靠线位的部分不会按猜测补齐；远期蓝图未完成审核前不会解锁自由扩建。

新建页截图：docs/campaign-0.17.0-new-city-1366x768.png、docs/campaign-0.17.0-new-city-1600x980.png。

各城市当前章节：上海3章、北京4章、广州2章、深圳1章、成都2章。完成样板章节会展示资料缺口；不会误报为已复原该城全部历史或截至2026年10月1日现状路网。

常用操作：
- 拖动空白地图平移，滚轮缩放；点击地点查看需求。
- 使用底部“车站”放置车站；使用“轨道”连接A/B端或连续铺设；使用“运营线路”按停站顺序创建线路。
- `R`旋转车站；`Esc`取消当前预览。`Ctrl+Z`撤销，`Ctrl+Y`或`Ctrl+Shift+Z`重做。
- 线路详情可检查、开通、延伸或修复；拆除运营线路不会拆除实体轨道。
- 默认暂停。点击顶部播放后查看真实模拟的等待、在途、完成、放弃与中断统计。
- 从存档中心使用自动保存、命名存档或JSON导入导出。旧版存档保留并可继续游玩，但不会自动计为历史章节完成。
