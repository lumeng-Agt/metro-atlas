# 桌面版测试记录

测试日期：2026-10-06（Asia/Shanghai）
构建目标：Windows 10/11 x86_64
Godot：4.7.2 stable，Compatibility 渲染器

## 已通过

- 五城首轮街区教学地点检查：各选一组相距 1—3 公里的住宅—学校／就业／枢纽需求；上海花木的住宅起点改为金桂小区、深圳西丽起点改为西丽蓝天、成都玉林起点改为玉林名居2期，均使用 OpenStreetMap 命名住宅区要素并记录来源 URL 与核验日期。北京玲珑花园、首都师范大学校本部及广州中山四路住宅楼—中山二路小学保留为教学点。客流标为游戏设定。
- 街区教学界面在 1600×980 与 1366×768 下原生渲染：教学首次暂停、镜头容纳 A/B 与任务卡、隐藏其他需求点和两侧抽屉，方向虚线标注“不是轨道建议”；本地瓦片缓存命中会安排重绘，首次打开不再停留在空网格。截图见 `tutorial-preview-1600x980.png`、`tutorial-preview-1366x768.png`。
- 五城教学完整流程：两处地点必须分别被两座已确认车站覆盖，只有这两站之间的连续轨道可以推进任务；独立车站、无关线路不能替代。目标需求真实进入模拟并获得服务后引导完成并暂停。撤销规划会重新校验步骤，不回退游戏时间。
- 出行时间单位回归检查：轨道区间米数先换为公里再应用公里／小时速度；800 米步行按 4.8 公里／小时约 10 分钟估算。

- Godot 项目资源扫描和脚本解析。
- 36 项规划数据／几何检查。
- 45 项街区教学检查；主动跳过也会记录为已看过且可手动重玩。另跑地图缓存烟测，当前教学街区的 20 张可见瓦片均从本机有效缓存读出并显示。
- 桌面交互流程烟测：放置两站、连接短区间、调曲线并检查里程变化、开通线路、撤销／重做且不回退模拟时钟。
- 四档界面缩放烟测：100%、125%、150%、175% 下正文和辅助文字尺寸同步变化，地图缩放保持不变；设置可写入并恢复。
- 开局页布局烟测：1600×980 与 1366×768 下菜单卡片均在视口正中，内容铺满卡片，不再挤在左半边；矮窗口会压缩次要说明，主要开局与存档按钮仍可见。
- 字体层级更新：正文主题 18px、辅助标签至少 15px、按钮至少 16px、地图标注至少 14px；游戏窄窗口会收起两侧面板以避免挤压地图。
- 端点命中优先级烟测：需求点与车站端点重叠时仍命中端点；短于旧版阈值的区间可接轨并开通。
- 网页 v7 存档迁移烟测：保留车站、站厅尺寸、双向站序、线路开通状态和发车间隔；区间标记为待复核示意线。
- 存档检查：写入 `%APPDATA%\\MetroAtlas\\saves`、读取最新进度、覆盖前保留 `.bak`。
- OpenStreetMap 瓦片网络检查：隔离环境烟测收到真实地图瓦片；原生截图在上海视野显示并绘制 16–24 张缓存／在线瓦片。使用受限并发请求，拒绝提示图不会作为底图缓存。
- 原生界面截图：菜单和运行界面分别在 1600×980 与 1366×768 下实机渲染检查；窄窗口侧栏收起，顶栏、地图图层、建设工具和底部状态仍可见。截图见 `menu-preview.png`、`menu-preview-1366x768.png`、`ui-preview-1600x980.png`、`ui-preview-1366x768.png`。
- Windows x64 程序启动烟测：从最终 ZIP 解压后，原生程序在无窗口模式推进 10 帧、正常 Compatibility 渲染运行 60 帧，退出码均为 0；截图与测试记录也包含在包内。
