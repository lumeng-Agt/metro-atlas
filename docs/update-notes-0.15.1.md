# 0.15.1 更新说明

- 修复自动存档说明被挤成竖排、载入按钮被撑成长条的问题。说明占据剩余行宽，按钮保持正常高度。
- 自动和命名存档列表显示可辨认的滚动条，并为滚动条预留空间，避免盖住载入按钮。
- 修复高缩放下存档窗口底部超出视口的问题；三档窗口和四档缩放检查覆盖两个分页、长名称与最后一项滚动。
- 主菜单尚未进入城市时，立即保存、新建命名存档和导出操作置灰并说明原因；修复主菜单导入被空会话保存检查阻止的问题。
- 从存档中心转入命名、导入或导出窗口时先解除原窗口的模态占用，避免新窗口打开冲突。
- 存档格式保持15，修复使用隔离数据目录，不读取或覆盖玩家正式进度。

检查结果及边界见 `docs/test-record.md`。本地仍仅保留固定名称的一个 EXE 和一个 Windows ZIP。
