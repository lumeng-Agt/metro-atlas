# 0.20.2：历史章节建设体验

- 熟悉基础操作后，可在“铺轨”工具中按本章站序连续选择相邻的已建设车站。地图逐段预览参考几何，所有区间经过完整校验后一次提交，并作为一步撤销；选错可移除最后一个区间。
- 章节确认后可以回看章初路网、查看本章新增站点与轨道、实际连接关系和后续接口，并主动保存PNG纪念图。
- 章节明确首次建设、延伸、分期、换乘、线路整理或方案调整的操作意图。上海1995主线及成都2015南延按延伸章节提示复用既有路段。
- 建设、接通和章节确认提供可关闭及可调节音量的短音效。
- 沿用存档格式20；不修改现有车站位置、历史里程碑及玩家路网。

## 本轮检查边界

Godot脚本扫描与自动回归通过。新增章节预览和成果计算耗时另见 `performance-0.20.2.json`。本轮没有完成人工新手观察、一小时运行、五城完整通关及干净Windows设备兼容测试；未测试的项目不会标成通过。
