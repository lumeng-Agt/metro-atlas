# 0.11.0 更新说明 · 2026-10-12

## 规划与运营可信度

- 车站端、已有轨道端及轨道分岔处的曲线预览现在继承接入方向，减少接头折角；预览、确认后的轨道几何和里程继续共用同一份数据。
- 轨道交叉按交点处的实际深度判断。只豁免接头附近，不再因为两条完整区间共用一个端点就忽略其它交叉。
- 创建运营线时可在可解析的替代走向间切换并确认。已保存线路固定使用的区间，新增捷径不会让已开通线路悄悄改道。
- 路径保存每站的发车时间偏移和运行方向。乘客容量按线路、方向、班次及区间区分，反向列车或另一条线路不会占用同一列车的载客容量。
- 存档升级为格式 11。读取版本 10 存档前单独保存原始 JSON，并尽量固定可解析的既有线路走向；无法识别的区段保留待整理标记。

## 地图与引导

- 修复分级地图缓存与缩放档位不一致的问题。
- 道路和建筑改为按屏幕可辨识面积过滤，避免因为 OSM 把一条路拆成许多短片段而整段消失；本地建筑仍只在近距离显示。
- 地图几何预先整理为米制坐标及批量绘制数组；平移时更新整体画布变换，减少逐顶点投影和密集街区重绘开销。
- 城市总览进一步减少短水系、细小道路和小片绿地，近站层减少小建筑描边；保留主要道路、河道及可辨认建筑轮廓。
- 新手卡先显示一个动作和完成条件；背景解释收进“为什么这样做？”展开区。
- 底栏只常驻显示等候、在途和已完成数量；其余运营指标放到悬停说明中，保存状态不再重复出现。

## 验收结果

- 规划几何 38 项、旅程与模拟 34 项、引导 47 项通过；原生建设流程、存档读写与备份、五城离线地图校验通过。
- 最大路网地图压力烟测覆盖城市总览、街区道路和近站建筑三个尺度；近站建筑场景为主要性能压力点。
- 本轮未进行导出程序的实体鼠标键盘完整试玩；测试记录单独标明了这一限制。
