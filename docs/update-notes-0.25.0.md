# 0.25.0 更新说明

本版把五城离线地图中的已开通线路关系接入里程碑章节，并允许在同一章节里逐项选择线路建设任务。目录有120个时间轴节点（上海22、北京25、广州25、深圳27、成都21），其中101个节点含铺轨目标；五城95条地图线路关系都至少被一个目标引用。旧档停在“资料边界”时会保留现有路网并回到首个未完成章节。

本版补充了截止日网络基准与覆盖报告，并升级到存档格式25。旧存档保留独立迁移备份；任务完成状态按稳定编号迁移，不会将一个旧节点错误地扩展成整段里程碑全部完成。

## 已知内容缺口

现有建设目标让地图线路可以逐项选择建设，但不等于五城逐站历史已完整复原：部分长线仍按进入地图当前范围的节点成组建设，中间分段开通尚未全部拆成任务；截止日仍在建、已批准及可选研究项目只有 19 项做成可玩的后续章节（广州12中段、广州13二期西段、广州8号线北延段支线、上海23号线一期、上海15号线南延、上海21号线一期、上海19号线、上海22号线崇明线、上海20号线一期、北京22号线平谷线、北京新机场线丽泽段、北京12号线东坝北街段、北京1号线支线、北京28号线、北京3号线一期东段、深圳17号线一期、成都18号线三期），其余仍在制作；只有政策方向的 4 项已改为可选，不再阻塞自由创作。地图几何为现代离线参考，不代表隧道测绘。详情见 `docs/campaign-content-audit.md` 与 `docs/network-coverage-2026-10-01.md`。

## 本版未完成的验收

尚未完成最终发行 EXE 的完整鼠标流程、五城从头到尾连续试玩、全部建设任务拓扑重放、四档缩放实机检查、压力性能测试、一小时持续运行、真人新手观察及干净 Windows 环境兼容测试。请勿把本版理解为五城全史完成版。
