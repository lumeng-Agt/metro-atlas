# 存档格式25迁移说明

格式25为章节新增稳定的线路建设任务标识，并让旧存档能从历史章节目录继续推进。迁移开始前，存档管理器会按原始文件内容建立一次独立备份。

格式24及更早的故事存档保留城市、站体、轨道、线路、换乘、撤销记录、教学状态和已确认的稳定章节编号。旧档若停在旧版 `history_gap`、章节编号失效或章节索引越界，迁移会查找最早未完成的稳定章节，从该章开场继续；不会把新加入章节的线路任务一并标为完成，也不会移动既有站轨。

当前任务选择保存为 `activeTaskId` 和所属的 `activeTaskChapterId`。标识失效或章节变化时，游戏会选择该章最早仍有未建目标的任务。自由创作副本仍保留独立游戏编号。

尚未确认完成的界面任务选择不会推进章节或历史事件。未知高于25的存档版本仍拒绝加载。迁移回归结果见[测试记录](test-record.md)。
