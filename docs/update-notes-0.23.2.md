# 0.23.2 更新说明

- 修复深圳2004章节中“轨道看起来已接上，但检查仍显示未接通”的旧档情况。原因是旧通用站体保留了轨道，新章节又有一个同位置、未接轨的线路专属站体；线路校验使用了后者。
- 对位置、方向和尺寸完全相同、轨道引用清楚的重复站体，章节检查会提供“保留现有轨道，修复站体关联”。确认后保留旧站位和所有轨道，移除孤立重复站体，并将保留站体绑定到对应线路目标。此操作可撤销；无法安全确认对象对应时不提供修复。
- 将“未形成有效线路”改为“尚未形成连续站序”，并说明先处理上方的站间连接问题。

存档格式仍为23，无格式迁移。程序不会自动改写玩家存档；需要在章节检查中明确确认修复。

本补丁通过50项换乘／站体修复定向检查及核心回归。尚未重新进行发行版鼠标试玩、性能和长时间运行测试。
