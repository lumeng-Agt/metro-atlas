# 0.24.0 开发更新说明

本轮建立五城截至2026年10月1日的截止日线路基准，以及按相邻历史节点划分的里程碑区间。深圳补入从一期十字网到2026年13号线北延的官方开通波次；地图关系、官方线路口径和逐线开通事实分开记录。

历史进度页在“历史章节缺口”和“远期规划缺口”两种状态下都会显示路网覆盖与未制作里程碑，不再因为进入 `future_gap` 而退回空白旧页。“后续资料待核验”也改为准确的“后续历史章节尚未制作”。

这次只修正缺口说明和覆盖信息的可见性，**没有增加可玩章节**。当前仍为13个已发布样章（上海4、北京4、广州2、深圳1、成都2）；深圳17个线路／支线标识和后续建设波次尚未转化为完整的逐里程碑建设内容，五城全史仍未完成。0.24.0固定名称开发包已重建，页面修复通过导出资源烟测。

存档格式升至24，记录稳定章节任务与历史事件编号。格式23及旧版迁移保留已完成里程碑，能够对应时补齐事件编号，不改动原有站轨。

官方来源及地图差异见[五城线路历史覆盖核对](network-coverage-2026-10-01.md)。本轮未执行发行版完整鼠标键盘试玩、性能压力测试或一小时运行；请勿把自动界面检查视为实机验收。
