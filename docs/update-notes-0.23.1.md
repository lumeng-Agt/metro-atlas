# 0.23.1 更新说明

- 修复采用深圳最终方案后，建设工具仍读取较早方案目标的问题。采用最终方案时，现在会使用该章正式建设范围中的全部线路和独立站体，地图、站区选择、建站和检查保持一致。
- 换乘目标现在按线路显示，例如“会展中心 · 1号线一期站体”和“会展中心 · 4号线一期站体”。地图近看也显示各自线路标签，不再把两座物理站体画成一个含糊的目标。
- 换乘按钮不可用时分别说明每座站体状态；就绪后按钮明确表示建立两座独立站体间的换乘关系。
- 补充说明：换乘是站体之间的历史联系，不会合并站厅或轨道。两条线路各有自己的车站和轨道，列车不会沿换乘关系行驶。

存档仍为格式23；本补丁没有改变玩家存档结构或模拟数据。
