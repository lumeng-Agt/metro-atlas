# 0.13.3 更新说明 · 2026-10-14

本次集中修正建设预览、吸附状态和小窗口操作，并补强隔离存档测试。

- 移动车站时实时预览相邻轨道；站体冲突、坡度或轨道问题会在确认前显示，错误位置以红色预览，取消或无效操作恢复原位。预览只准备当前站点及关联轨道数据，不深复制整座城市。
- 旋转站体会同步调整接轨曲线控制柄，使站端保持顺接。角度输入支持 0.1° 步进，15°仍作为快捷旋转量。
- 端点和自由轨道节点一起比较屏幕距离。密集位置提供 A／B 候选，地图候选、详情选项和当前操作状态同步；取消选择会同时清理临时状态。
- 站体移动、旋转、车型和深度修改使用同一建设预览校验与整步撤销流程；草稿保存规划版本、预览几何、问题和受影响线路。
- 底栏按当前工具内容计算高度并把确认／取消／结束按钮分开放置；窄窗口侧栏互斥，点击空地图可收起。教学定位避开教学卡和底部操作区。
- 存档、继续游戏索引、设置与恢复副本共用同一数据目录。新增 `--data-dir <路径>`／`--data-dir=<路径>`，便于完全隔离测试。
- 继续游戏、导入、迁移和恢复前关闭文件并执行结构与引用校验；错误存档不会被空白规划覆盖。保存检查复用加载校验，避免无效坐标、轨道引用或模拟容器进入新存档。
- 无效 JSON 通过无噪声解析返回明确错误；恢复副本只有写入完整后才报告成功，失败时指出原始备份仍保留。

存档格式仍为 13；没有改变时钟、完成出行、历史和运行规则。
