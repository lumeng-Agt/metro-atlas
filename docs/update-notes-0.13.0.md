# 0.13.0 更新说明 · 2026-10-13

本次更新让列车时刻、乘客占用和运营统计沿同一条事件时间线推进，并把常用运营信息放到可直接查看的界面中。

## 运营时间与容量

- 模拟状态保存累计游戏秒。列车到站、乘客下车、步行到站、发车、排队上车和离站按时刻处理；同一时刻先下车，再接收步行乘客，之后上车并发车。
- 活动列车保留自己的线路方向、路径快照和逐站时刻。单纯调整发车间隔只安排之后的发车，不会重写已发列车或把过去班次补发。
- 乘客上车只占用当前实体区间的载客量。列车到站后释放已经驶过的区间；继续乘车的批次再进入下一段。满载批次拆分，没上车的部分继续排队。
- 变更运营中的轨道几何或线路路径时暂停并终止受影响班次。乘客从最后记录的有效车站重新寻路；找不到路时明确计入中断，不能误记为到达。
- 站内候车、出行完成和时钟仍由模拟事件推进；显示动画只读取活动班次。保存的等待和乘车时间标记使用标准 JSON 数值。

## 界面与地图

- 左侧拆为“线路、任务、统计”三页。统计页直接列出发起、等候、在途、完成、放弃和中断人数，并解释每项定义。
- 运行推进后保存状态立即标为“未保存”；保存失败保留失败提示，并可点击重试。
- 地图列车使用独立绘制层；常规列车动画只更新列车图层，地图底图及站点只在视图或模拟数据需要时重绘。
- 离线地图缓存按使用情况维护最近访问顺序，并保留 256 MiB 缓存目标及可见分块保护。
- 站点周边道路标签按重要程度合并近距离同名项，避免同一条被切分的道路重复铺满地图。
- 重用按规划数据生成的线路网络，并按当前事件索引到站列车、候车队列和乘客；改变班距或规划数据会刷新网络缓存。

## 存档与验证

- 存档格式升级到 13：版本 12 的差量操作历史继续保留；旧时钟转换为累计游戏秒；加载后暂停。
- 新增同刻处理、非整分钟到站、班次调整不追溯、当前区间容量、运行中改线乘客守恒，以及 12 版撤销历史迁移检查。
- 不改变城市、需求、车辆或现有轨网的地理位置。客流、车辆性能和容量仍是游戏模拟，不是运营预测。
