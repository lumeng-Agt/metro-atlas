# 0.26.0 更新说明

本版改的是「玩到最后」这件事，不是内容数量。

**自由创作改为按玩法完成度解锁。** 之前的判定要求独立资料核对全部通过，而五城核对一直没做完，结果玩家通完全部章节也看不到「进入自由创作」。现在判定只看玩家自己的进度：五城已发布章节全部完成、本章已结算、存档校验通过、必做项目的线路几何核对通过，即可解锁。资料核对的结果仍然照常产出，但只写进审计信息，不再拦人。

**发行门槛从资料审计改为玩法验证。** 打包前会要求一份当次跑出来的玩法验证记录：五城从零重放、五城断点续玩、关键专项测试全部通过，且记录的源码指纹与当前工作区一致。指纹对不上或有一项没过，就打不出包。资料侧未完成的 11 项不再阻断发行，改为在本文档里逐条列明。

**补上了三处「承诺了但没证」的地方。** 撤销上限 200 步、按钮最小高度 44 物理像素现在有断言；自由创作有了一条端到端正例——在真实城市里通关后解锁，并存盘重载确认解锁状态保留。

**修掉了两条本来就过不了的检查。** 存档往返检查一直借用上一次重放留下的存档，单独跑必然报错，现在自己造存档场景，并加了「造空了就直接判失败」的断言，避免它对着空数据空转。深圳 13 号线那条「单线成功不能算全城完成」的断言是按旧的资料门禁写的，门禁改成玩法口径后它永远不可能成立，现在改为核对官方范围审计确实报出缺失的城市范围。

本版玩法验证记录：26 项全过，0 失败。五城从零到最后一章的重放检查点为深圳 110、上海 143、北京 139、广州 127、成都 114，全部抵达并确认可进入自由创作；五城断点续玩分别为 77、101、106、92、87。记录连同源码指纹写在 `docs/gameplay-verification-0.26.0.json`。

**导出包去掉了不该带的东西。** 之前打出来的 exe 里混进了 `release-candidate/`、`.tmp-probe-*.gd` 调试脚本和 `.tmp_*.json` 地理编码中间数据，现在这些都被排除，包内只剩 `data/ scripts/ scenes/ fonts/ assets/`。

版本号 0.26.0；存档格式仍是 25，旧存档不需要迁移。

## 已知内容缺口

五城 170 个章节（含 60 个远期项目）都可玩，但**独立资料核对仍有 11 项未通过**：上海 4 项（历史里程碑、截止日开通时序、截止日换乘清单、19 号线换乘覆盖）、北京 4 项（历史里程碑、13 号线扩能、亦庄连接线、11 号线二期）、广州 1 项（历史里程碑）、成都 2 项（项目清单、历史里程碑）。这些属于「证据还没补齐」，不影响本版可玩范围，也不代表已核对通过。

部分长线仍按进入地图当前范围的节点成组建设，中间分段开通尚未全部拆成任务；地图几何为现代离线参考，不代表隧道测绘。详情见 `docs/campaign-content-audit.md`、`docs/network-coverage-2026-10-01.md` 与 `docs/history-two-source-2026-10-29.json`。

## 本版未完成的验收

尚未完成：真实鼠标全流程试玩、五城连续试玩观察、四档缩放实机检查、一小时最大路网连续运行、真人新手观察、干净 Windows 环境兼容测试。性能未在本版重测，`docs/performance-0.26.0.json` 沿用 0.25.0 实测基线；其中保存世界耗时 112–120ms 仍超过 100ms 的主线程阻塞目标，本版未优化。
