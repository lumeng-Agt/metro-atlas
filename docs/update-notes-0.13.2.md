# 0.13.2 更新说明 · 2026-10-14

本次重点是保护未保存的规划，并让车站选择、移动、车型替换和线路走向更可靠。

- 退出、回菜单和切换城市前会暂停并完整保存世界与继续游戏索引。保存失败时可以重试、另存 JSON、明确放弃未保存修改或留在当前游戏；取消不会离开。
- 切换城市和载入存档区分“没有存档”与“存档损坏／读取失败”。损坏文件保留，不会被自动创建的空白世界覆盖；继续游戏索引也会尝试读取备份。
- 点击站体内部即可选中，车站移动工具可拖动或点击新位置；端点吸附优先最近目标，缩放后 A／B 端靠得太近时会提供单独选择。
- 车站移动、旋转、深度和车型变更会检查旋转站体重叠、相邻轨道接点、坡度和交叉。曲线控制点修改也会阻止自交、零长度、超坡度或同层冲突，并保留上一个有效方案。
- 车型替换按真实站体矩形检查冲突。线路改用较短编组不会缩短既有或共用车站；长编组增加站体长度前会检查相邻轨道，操作作为整体可撤销。
- 车站详情固定站名、移动、旋转、接轨和删除操作；属性在中间滚动。界面放大时建设按钮尺寸有上限，减少底栏挤占地图。
- 创建线路时可以回看任意相邻停站区间并切换可用物理轨道走向；吸附重合的车站端点提供明确的 A／B 选择。

存档仍为格式 13，游戏时钟、已完成行程和撤销历史语义不变。模拟客流和工程约束继续属于游戏估算。
