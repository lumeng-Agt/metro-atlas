# 0.29.0：界面重构与规划提案

本轮重做主菜单与工作台的界面语言，并补充规划提案系统。世界存档格式不变，不重置旧路网。

## 界面

主菜单与工作台改为脱离边缘的浮动卡片：卡片有圆角、投影和明确的边界，不再贴着窗口边缘铺满。菜单去掉滚动容器，卡片高度按内容计算，不再出现内容下方的空白尾巴。

章节卡片的事件页只保留一个主按钮（载入城市史志），出处链接降为次要文字链接。顶栏去掉与胶囊按钮冲突的深色 METRO 标签，城市与时期单独承担身份信息。入口按钮去掉左侧彩色竖条，工具类动作改为轻量文字链接。

地图提示框按地图区域居中，不再按卡片左侧的剩余空间定位。

**已知修正**：1366×768 在 150% 与 175% 缩放下，菜单条目按比例放大后会超出窗口并被推到屏幕上方。现在菜单按可用高度限制条目缩放，三种分辨率与四档缩放的组合均通过布局检查。

## 规划提案

章节可以以规划提案开场：玩家在正式施工前先排布公共站点，方案按历史记录评分。提案阶段有自己的存档与恢复边界，兼容旧存档。

## 内容

深圳作为首发城市，加入带出处的决策卡片与历史跳章。本轮重新生成网络覆盖审计，使其与当前数据一致。

## 验证与边界

游戏验证 39 项全部通过（`gameplay-verification-0.29.0.json`）。布局检查 267 项通过，覆盖 1366×768、1600×980、1920×1080 与 100%／125%／150%／175% 的组合。

持续集成此前从未成功运行：工作流用 `$LASTEXITCODE` 判断 Godot 步骤，而 `setup-godot` 放在 PATH 上的是包装脚本，PowerShell 不为它设置该变量，`$null -ne 0` 恒为真，于是导入步骤与全部测试步骤无条件失败。本轮改为按输出与 `$?` 判断，并让失败时打印具体行。CI 现已通过。

真人新手观察与干净 Windows 兼容性仍需外部条件；未取得时不冒充通过。
