# 0.23.0 更新说明

- 修正历史目标圈的点击范围，使可见范围、悬停和点击采用同一半径；重叠目标和实体站体进入明确选择，不再默认选列表第一项。
- 确认放置车站后保留建站工具，并自动突出下一座未建设的目标站。
- 增加历史服务范围的预览与确认。北京样板按明确区间分别记录建成、试运营和正式开放状态；这些记录可以撤销，不能由章节文字自动代替玩家操作。
- 换乘联系由玩家明确建立，必须关联线路专属物理站体；几何相交、同名或相邻站不自动算换乘。
- 自动存档回到单槽方式：每300秒检查一次，有持久修改才覆盖；手动保存、确认历史节点和离开游戏会立即保存到同一槽。新版不会继续生成时间戳自动历史。
- 修正格式23继续游戏索引识别和恢复副本处理。旧格式迁移不推断未保存的历史服务状态。

## 已知内容缺口

目前发布的仍是13个早期样板章节，并非五城全史。覆盖台账显示大量地图站点尚无可玩历史章节；地图快照晚于2026-10-01目标日期，因此不能用地图对象数宣称截止日运营网络已完整。上海、深圳整城历史、其他三城整城历史和逐对象官方开通资料仍待补齐。

## 本轮验证边界

自动脚本回归和五轮独立进程续玩通过。最终发行程序的完整鼠标试玩、全部窗口与缩放、长时性能、真人新手观察和整城通关不在本次自动回归覆盖内，不能据此标为通过。
