# 存档格式22→23

格式23为世界规划增加历史服务范围记录，并让章节中的“建成、试运营、正式开放”成为可预览、确认、撤销的明确操作。状态按线路和连续区间保存，不会因为站区重叠而自动建立换乘或开放整条线路。

读取22版存档时，程序先保留原始内容备份，再迁移到新的字段结构。迁移保留城市、游戏编号、站点、实体轨道、线路、历史章节、里程碑、故事阅读状态和撤销记录。旧档没有明确服务范围时，迁移不会猜测填入状态；相关历史需由章节操作或后续核验补充。

继续游戏索引也接受格式23。无站点的精简索引按版本号及游戏编号验证；损坏时检查备份，未知的更高版本仍拒绝载入。保存继续索引时保留可用恢复副本。

自动保存继续使用每局唯一的自动槽，每300秒检查一次，仅在持久内容发生变化时覆盖。旧格式产生的时间戳自动历史文件不会被迁移或自动删除，可以在存档中心逐份清理。手动另存仍创建独立命名副本。
