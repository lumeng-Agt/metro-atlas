# 0.22.0：物理站体换乘与五城历史覆盖审计

- 车站现在区分历史站区和线路专属的物理站体。一个换乘站区可有多座车站实体；每条线路绑定自己的实体，显式换乘关系另存，不作为轨道边。
- 深圳2004年一期章节将会展中心建成两个独立站体，并逐项检查1号线、4号线与各自站体的对应关系。
- 规划评估和存档校验会拒绝同名／邻近但没有显式换乘边的站点、错误的站体—线路配对及无效的站区引用。
- 存档升级为格式22；格式21继续索引保留可读取。迁移补齐旧站体身份，不自动推断旧站厅结构。
- 新增可重复运行的五城线路覆盖审计，逐条列出地图包站序、历史章节站点编号覆盖和缺口，并将地图快照晚于截止日这一限制写明。
