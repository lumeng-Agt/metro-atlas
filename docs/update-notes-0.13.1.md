# 0.13.1 更新说明 · 2026-10-14

本次更新修复继续游戏时的保存错误，并让教学、车站详情和运营变更的反馈更清楚。

- 继续游戏读取索引后立即关闭文件，再载入城市并完成世界存档与继续索引的整套自动保存。保存失败保留失败状态，点击“保存失败 · 重试”会重做完整保存；错误窗口显示具体原因并标为“保存失败”。
- 主菜单和设置内容保持在窗口内并可滚动；界面缩放只调整字号，不再把菜单控件尺寸重复放大。统计行、建设栏和地图图层控制按窗口空间排布，重载城市时先清除旧图层，避免控件叠加。
- 教学卡按钮随步骤显示“建站、确认轨道、确认线路、开通或观察”等动作；进入接轨步骤时自动显示两座目标站。任务起终点不再重复绘制普通需求标签。
- 新建站默认使用不重复的编号名称。选中车站会展开详情；移动、旋转、调整深度和车型、调整运营轨道或班距、拆除车站／轨道／线路时，如影响已运营服务，会先说明受影响线路和列车，取消不改规划，确认后操作仍可撤销。
- 教学完成和运营统计共用实时到达人数，并在完成卡区分实际到达与游戏模型估算。完成后任务页会推荐教学街区附近未服务的需求。
- 自由铺轨标为“自由端点、待连接”；实际吸附到站端或既有轨道时才显示吸附提示。
- 修复更改界面缩放时设置窗口随主菜单重建而关闭的问题；菜单完成重排后会保留在设置窗口中，并显示刚选的档位。

本版没有新增存档字段或改变存档格式。游戏模拟、地点客流和车辆参数仍为游戏设定。
