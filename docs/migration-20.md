# 格式20迁移

读取19前在独立数据目录originals下按原始内容SHA-256保留v19备份。成功后增加参考资料版本，保留游戏编号、路网、里程碑、故事和操作历史。原文件不由读取操作覆盖。

已建车站不会跟随参考位置校正而移动，既有轨道不会被新走廊替换。继续建设时可查看参考与正式建设差异；如需采用新位置，先另存副本并手动调整，确认可撤销。不能自动把完成的旧章节判为未完成。

新建轨道保存referenceAlignmentId、referenceVersion与独立referencePoints，重载或资料更新后展示不自行改道。手动、自动、继续、导入和恢复共享校验；折线坐标及端点引用均需有效。未知版本拒绝加载。
