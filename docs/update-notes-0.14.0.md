# 0.14.0 更新内容

- 教学通过实际地图和底栏操作推进：查看需求、建站、铺轨、创建运营线路、在线路详情开通，再用顶部播放控件观察乘客。教学主按钮只定位当前步骤，不代替玩家建设。
- 教学结束后开放四段持续城市议程：周边扩建、重要目的地、真实换乘和高峰服务。每次只突出一项目标，并提供不超过两项可选委托。
- 五城各配置住宅入住、就业增长和定期临时活动。系统提前预告地点与开始时间，固定日程和触发状态保存到本地；客流变化为游戏设定，不会在重载后重新随机。
- 建设阶段可命名并指定最多三组出行作为服务目标。阶段卡显示车站、轨道、线路、未开通区间，以及每组需求由本阶段接通、其他阶段已服务或尚未接通的状态。
- 车站可标记为拟换乘节点，帮助比较未来线路走廊；该标记不等于换乘。实际换乘要求两条已开通线路停靠同一站，并有真实跨线到达。
- 分开展示覆盖、完整出行时间、候车／拥挤和换乘负担；没有实际完成样本时显示“暂无结果”。成果比较要求同一需求组、日内时段和城市事件状态。
- 本地存档格式升至15。版本14迁移前保留独立原始备份；规划、时钟和已完成出行保留，章节从当前网络状态接续，事件沿固定日程计算并保存触发状态。
- 增加街区挑战入口，挑战目标与自由规划共用同一份空白城市存档；可以退出目标层继续自由扩建。
- 线路班次增加“全天统一／分时段”。分时段使用游戏时间的早高峰、晚高峰和平峰配置；进入新时段时只重排尚未发出的班次，已运行列车时刻保持不变。
- 增加规划、需求、可达性和运营问题四种地图分析模式。可达性按完整旅程耗时分组，站外接驳仍明确采用直线步行估算。
- 统计页保存最近七个游戏日的15分钟统计桶，并以确定性抽样记录最多1,000条实际乘客批次事件；抽样不会影响客流模拟。
- 预计旅程可展开显示步行接驳、候车、乘车和换乘耗时；已记录旅程可查看班次、到站及到达事件并定位地图位置。
- 增加可展开的规划复杂度摘要：里程、最深深度、曲线区间和换乘站数量；这些是游戏内比较指标，不是工程评分。
- 设置新增轻量操作提示音开关和音量，保存在本机偏好文件中。
- 版本13及更早存档按原有迁移链升级；旧固定班距保留为全天统一，缺失的章节统计和旅程记录不会被补造。
