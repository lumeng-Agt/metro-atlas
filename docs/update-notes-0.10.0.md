# 0.10.0 更新说明 · 2026-10-11

## 地图与建设流程

- 五座城市现在使用随游戏安装的 OSM 矢量地图：城市尺度保留主干路、水域与绿地，放大后逐级显示次要道路、路名和淡建筑轮廓。餐馆、商店、公交站等底图图标已移除；地图不会请求在线瓦片，断网仍可正常规划。
- 建设顺序改为“放置车站 → 铺设物理轨道 → 创建运营线路”。新站自动带站台与双向站内轨道，空白开局不再预置运营线路。
- 地下轨道可从站端、空地或已有轨道中段起铺；支持直线、曲线、连续铺设、道岔拆分确认和 5 米步进的深度调整。确认和预览使用同一条几何。
- 运营线路独立引用实体轨道。多条线路可共用轨网；删除一条运营服务不会拆除物理轨道，交叉轨道也不会自动连通。
- 新手流程同步调整为先建站、铺轨，再安排停站并开通。

## 兼容与资料

- 本地存档升级为格式 10。版本 9 原始档单独备份；旧线形继续保留并标注待核验，不会因几何交叉自动合并。
- 随包地图数据从 Geofabrik 的 OpenStreetMap 省市提取包生成，清单包含范围、来源日期、源文件校验值和 1,667 个分块校验值。派生地图数据库依 ODbL 1.0 分发。
- 地图仅作视觉参照，不代表已获得完整步行网络、建筑测绘或工程校核数据。
