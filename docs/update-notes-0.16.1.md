# 0.16.1 更新说明

- 存档中心现在可以删除自动进度、单份自动历史和命名存档。删除自动进度会同时清理其恢复备份、自动历史，以及指向该进度的继续游戏记录；其他城市和独立命名存档会保留。
- 当前正在使用的自动进度会暂时禁止删除，返回主菜单后即可删除。删除前会显示具体对象与影响范围；失败时保留错误信息和未完成文件。
- 新建城市的“从零规划”页面增加教程开关，每次默认开启，不再被以前完成或跳过教程的全局标记关闭。关闭后进入自由规划。
- 继续游戏和命名存档按各自保存的教学状态恢复；“当前进度另存为…”明确说明它只会复制当前进度，不会新建游戏。
- 修复教学中A/B需求标记与普通需求图层开关脱节的问题；即使为简化画面隐藏普通需求，当前引导标记仍可点选。聚焦建设确认步骤时会自动滚动详情区，使箭头指向真实可见的确认按钮。
- 本版沿用存档格式16，没有改动模拟规则。

回归结果：存档删除23项、教程与新开局90项、存档读写检查、原生界面流程，以及存档中心895项布局检查全部通过。详细范围和未执行项目见随包测试记录。
