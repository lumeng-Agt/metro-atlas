# 0.19.0：清晰地图、首章教学与地点故事

本版于2026-10-17更新，存档格式19。继续使用固定名称的游戏程序与Windows ZIP。

- 地图改为浅灰街区、蓝色河湖、绿色公园、清楚的道路描边与建筑轮廓。主要路名沿道路显示；重要公共建筑保留，普通楼名减少。普通加载和缓存绘制使用同一份样式。
- 只有首次首章教建站与接轨；确认首章后停止引导，其他城市不再自动重复。跳过与学会分别记录。顶部及菜单可以进入独立的基本操作练习，保留原进度。
- 已发布的五城13章各加入一则地点故事。选中相关地点或建设对应区间时可出现，地图“史”标记与资料页可以重读；已读状态随存档恢复。
- 当前年代跟随所看的方案，深圳初始方案显示1998年，不提前显示2004年开通日期。方案调整提供新增／移出目标及旧、新图层预览，需确认后才修改目标。
- 历史方案可在资料页只读对照；开始建设时返回正式方案。未实施草案不生成展示线路。
- 站点与章节支持独立的建设配置、来源和参数状态。成都B型六节及南延线地下站使用发改委批复信息；整列精确总长、原始站体尺寸与埋深仍缺资料，界面明确标作游戏示意，不宣称已实测复原。
- 格式18原始存档在迁移前按内容独立备份；游戏编号、已有站轨、里程碑及历史保留。新界面不再让后续章节沿用首章箭头。
