# 0.13.5 更新内容

- 运营线路的详情现在逐段列出相邻停站。区间断开时可以进入“修复”，查看并选择重新铺设后的候选走向；修复只替换选中的区间及其反向路径，线路保持暂停，需再次检查并开通。
- 修复走向可保存、重载、撤销和重做。新增轨道不会暗中改写已确认路径；待接通线路可以保存，但不能运行。
- 曲线修改在影响确认期间保留预览，并在提交前重新检查规划版本；无效或取消的预览不会写入正式规划。
- 从备份恢复前显示备份来源和时间。只有确认且成功写入独立恢复副本后才载入；写入失败时保留当前会话和原文件。
- 调整建设栏的实际容器布局，避免底部操作按钮被地图署名覆盖；署名缩为单行并留在地图内。撤销后仍存在的对象会继续保持选中。

站距仍不作为开通门槛。运行客流和建设参数继续是游戏模拟，不代表现实规划或工程校核。
