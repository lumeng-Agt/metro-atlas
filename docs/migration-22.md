# 存档格式19—21→22

版本22为历史站区和实体站体增加独立身份，并将换乘联系保存为独立关系。轨道图仍只表示可铺设、可行驶的实体轨道；换乘边不能被列车寻路当作轨道。

读取旧存档前按原始文件内容生成迁移备份。版本19、20、21会保留 `gameId`、当前章节与步骤、已确认里程碑、线路、车站、规划历史及原参考数据之外的字段；在新版本中补齐换乘容器与站体身份。已有车站获得稳定的 `stationInstanceId`；旧记录按已有历史站点标识建立站区关联。迁移不会仅因为两站同名、靠近或属于不同线路就自动创建换乘关系，也不会猜测站厅、站台层数、通道或共用站体结构。歧义由内容配置或玩家在后续建设中明确处理。

单线旧站保持原几何与线路归属。旧版本把多条线路压在一个车站对象中的记录暂时保留原对象，不会自动拆成多个实体站体，以免擅自移动站点、改变轨道连接或伪造换乘。新章节可为线路分别建设实体站体，再显式记录换乘。

更早版本仍按既有“旧路网作品”迁移流程处理。当前只对深圳2004年会展中心示例加入了两座线路专属站体和显式换乘关系。其他旧档和章节不会因格式升级自动获得新的历史结构。迁移回归覆盖19—21格式的章节与里程碑保留、身份补齐、换乘引用校验、继续索引和独立站体序列化。
