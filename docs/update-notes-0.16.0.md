# 0.16.0 更新说明

本版把基础建设后的扩建、运营观察和本地续玩接在一起。

- 在线路详情可选择从起点或终点继续扩建。新增车站与走向确认后保留线路原编号，线路会暂停；检查并重新开通由玩家决定。
- 车站详情显示未接轨、已接轨未运营、运营中或待修复状态，便于辨认网络当前处于哪一步。
- 统计页新增线路方向的载客率、峰值载客与空载区间比例，按最近一小时的模拟样本计算；样本不足时显示无样本，不据此阻止开通。
- 自动存档中心列出每座城市、每种开局最近三份有效历史，可查看保存时间和游戏进度后确认载入；显示自动历史占用空间。
- 版本16存档新增有界线路利用率记录。版本15及更旧格式迁移会初始化为空，不补造历史运营样本；版本15原始存档迁移备份规则保持有效。
- 修复网页旧存档迁移到版本16时缺少利用率统计容器，以及同一秒内新旧自动历史排序不稳定的问题。
- 修复新载入界面在首帧地图尺寸尚未就绪时，教学聚焦层产生负尺寸几何并反复记录错误的问题。

完整操作、迁移和已知限制见随包 `README.txt` 与 `test-record.txt`。
