# 0.9.0 更新说明 · 2026-10-11

## 线路和出行

- 新增统一线路路径结果：开通检查、行车时间、地图预览和列车绘制按同一套轨道区间与停站顺序计算。
- 行车时间加入车型速度、加减速、曲线限速和停站；修正区间米数与公里时速的换算。
- 选路按预计全程时间比较起终点周边可用车站。仅同一车站对象可形成线路换乘；站内换乘时间单独估算。
- 乘客按批次经历接驳、候车、登车、乘车、换乘和到达。容量不足时保留排队，等候超过 30 游戏分钟会记录为放弃；到达后才计入已完成出行。
- 线路调整后，受影响的乘客会在最近的有效车站重新寻路，无法继续的行程独立计为中断，不会计作到达。
- 游戏时间跨午夜后继续累计。统计区分出发、等待、在途、完成、放弃和中断。

## 街区目标和存档

- 教学后根据当前规划与模拟状态提供最多三项扩建/运营目标；目标改善结果使用同一需求组前后各 60 分钟数据比较。
- 本地存档升级到格式 9。版本 8 原始存档保留为独立迁移备份；旧版完成量归档为历史估算，新版只统计实际到达。
- 存档写入、继续游戏索引和 JSON 导入导出使用明确的成功/失败反馈；损坏时提供备份恢复并保留恢复副本。
- 地图缓存站体和区间的米制几何，绘制时按当前视野裁剪区间；街区尺度以下才画站体细节。上海最大路网的连续缩放/平移压力采样从 15.4 提升到 69.2 平均 FPS。

## 已知限制

城市接驳使用直线步行估算；同站换乘采用统一的游戏时间估算。现实路网中无法解析的站序会标为待整理。客流和车辆运行是游戏模拟，不是现实预测。本版不含手动信号、车辆段、地下站厅编辑或逐名乘客动画。

## 验证

自动检查：28 项旅程/模拟、45 项教学、36 项规划几何，以及迁移、存档、UI 和瓦片缓存烟测。上海最大现实路网的一游戏小时模拟为 119.6 ms；1600×980 连续地图重绘平均 69.2 FPS（180 帧压力采样）。发行包启动检查和完整设备数据见 `test-record.md`。
