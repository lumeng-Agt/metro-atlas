# 0.13.4 更新说明 · 2026-10-15

本次优先保护存档和既有线路，再整理开局与建设操作界面。

- 删除运营线路正在使用的轨道时，会暂停受影响服务，并把失去的区间保留为待修复状态。这样的规划可以保存、退出后继续；线路检查会阻止未修复的服务开通。撤销和重做会同时恢复轨道、线路路径与运行状态。
- 移动或旋转车站时，连接的轨道会随草稿预览。横移站体时自动把直线接头转换为保持两端方向的曲线；曲线预览和确认使用同一套几何与检查。预览只复制正在改动的站点、节点和关联轨道，减少大路网拖动卡顿。
- 站端顺接纳入轨道几何校验；调整曲线时持续显示无效原因，松开后仍会再次校验。新增捷径不会悄悄替换已确认线路的走向。
- 主存档与“继续游戏”索引都会在覆盖前校验并保留备份。主文件损坏或结构无效时尝试读取有效备份；恢复前先写入独立恢复副本。恢复副本失败会停止载入，避免在数据未保护时继续覆盖。
- 主菜单改为居中的规划工作台；新建城市移至独立页面，城市与“从零规划／扩建路网”选择不会挤在开局首页。
- 发行目录维持固定名称的一份 EXE 和一份 Windows ZIP。构建脚本先在临时目录验证 ZIP 完整性与包内 EXE 哈希，再成对替换稳定版文件，不生成每版 EXE 或源码压缩包。

存档格式仍为 13；累计时间、已完成出行和撤销历史语义不变。
