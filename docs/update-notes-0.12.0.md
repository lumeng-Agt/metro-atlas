# 0.12.0 更新说明 · 2026-10-12

本次更新优先处理扩建后线路走向变化、列车与乘客模拟脱节，以及大城市地图拖动卡顿。

## 线路与运行

- 已确认的运营线路逐段保存轨道编号和行驶方向。新增捷径不会让既有线路自动改走；轨道拆分会在同一次修改中更新正向和反向线路引用。
- 线路预览和运行读取同一组有序轨道。曲线半径进入游戏速度估算，因此较急的弯道会增加运行时间；这是简化模型，不代表工程限速。
- 模拟列车记录方向、发车时刻和逐站到发时刻。乘客按具体班次的剩余容量上车，到站下车后释放该列车的载客量。
- 地图列车按实际活动班次和轨道路径插值，不再均匀循环展示。版本 12 存档保留方向路径和可恢复的班次状态。
- 读取旧存档会依原始内容生成独立备份。版本 11 已锁定路径继续保留；无法安全解析的线路会提示待整理。

## 地图

- 五城道路按尺度分层：总览显示快速路和干道，进入城区后显示城市主路，再放大显示次要道路、住宅道路与建筑轮廓。道路短片段不会因单段长度直接消失。
- 分块索引只在切换城市时建立；地图文件解压、投影、三角网及绘制批次准备在后台进行。地图加载期间保留已显示内容，过期视图结果会丢弃。
- 城市总览线路层采用较轻的单线绘制，减少道路与线路重叠时的视觉负担。

## 本地开发与迁移

- 存档格式升级至 12。
- 离线底图根据新增道路层级重新生成，五城仍随发行包提供。
- 变更代码位于 `scripts/route_path.gd`、`scripts/track_network.gd`、`scripts/simulation_engine.gd`、`scripts/map_view.gd` 和 `scripts/save_manager.gd`；回归脚本见 `tests/`。
