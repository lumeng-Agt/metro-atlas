# 0.14.2 更新说明

- 新增独立手动存档：可命名并保留多份进度，从主菜单或游戏内载入；载入前先保存当前进度，恢复后默认暂停。
- 新增定时自动存档设置：默认每 5 分钟现实时间保存未保存的进度，可关闭或选择 2、5、10、15 分钟间隔。
- 建设确认、暂停、窗口失焦和退出时继续即时保存；保存失败保持明确状态并可重试。
- 手动存档列表会验证文件；损坏文件会标为不可载入。手动存档可在 `%APPDATA%\MetroAtlas\manual_saves` 管理。
- 存档格式仍为 15，不迁移或改写既有玩家存档。

验证：规划42项、旅程与模拟73项、城市章节64项、教学83项、手动／自动存档检查及原生界面流程均通过。自动计时使用隔离存档验证；本轮未执行发行 EXE 的完整鼠标键盘试玩或长时间性能测试。
