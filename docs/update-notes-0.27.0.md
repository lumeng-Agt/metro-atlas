# 0.27.0：历史收藏与地铁挑战

本轮保留历史蓝图建设，增加收藏和独立练习。世界存档仍用格式25，不重置旧路网；挑战成绩另存为本地格式1档案，无账号、服务器和排行榜。

## 从哪里进入

- 章节成果页或故事时间轴：观看发展史、导出视频。
- 章节成果页：线路图视图及PNG导出。
- 主菜单“地铁挑战”：五题站位挑战、站名默写、每日一题。
- 设置：建设反馈音量、减少动画、展示合成报站开关。

## 发展史与纪念图

回放只恢复本存档已经确认的里程碑差量，不自动补齐玩家没完成的建设。历史与规划分栏，按实际记录显示当时站名、线路关系和开放范围；记录缺失或不一致时明确说明可恢复边界。

新增路段逐段亮起，支持暂停、节点跳转、30／60／120秒选择。视频使用独立1920×1080、30FPS渲染场景，导出VP9 WebM；成功校验后才替换目标，取消和写入失败保留原文件。视频当前为无声导出；合成报站用于游戏中的展示播放。PNG只在主动点击时生成。

线路示意图从有效线路路径取得站序，保留物理站体和明确换乘，不把交叉自动当换乘。规划线路使用虚线。全网标签放不下时扩大可滚动画布；布局在线程中计算，不改变正式轨道。输出标明“游戏线路示意图”，不是官方线路图。

## 独立挑战

站位挑战每局5题，可选择城市和已发布时期。道路、水系和地标仍可见，目标圈、地铁蓝图和吸附隐藏。提交后显示落点、参考位置、偏差连线及结果。

**按用户确认的规则，奖牌相对游戏参考坐标计算，不代表测绘精度。** 金牌≤100米、银牌≤250米、铜牌≤500米；显示距离按10米取整并写“约”，奖牌使用未取整距离。提示或重复每日题为练习，不影响主线。

默写接受规范化空白、全半角及资料中记录的曾用名；换乘按历史共同身份去重，同名异站需要选择。显示本期名称与已记录别名，保留独立答对／提示记录，可关闭后续答。输入法组字时不提交。

每日题按北京时间和题库版本读取固定日期。题库2026.10.30.2含32道基础题：25道站位、2道曾用名、5道事件顺序题，安排180个明确日期，轮换复习，**不是180道独立题**。超出日期范围进入普通练习入口，不循环冒充新每日题。首次结果不覆盖；分享卡不带答案、坐标、本地路径或存档编号，内部含站名的题号转为短散列题号。

## 反馈、声音与发行

落站、接轨、换乘与章节确认增加短反馈；普通建设问题尽量贴近草稿显示，需要选择的保存／覆盖／删除仍用对话框。减少动画与静音可独立控制。

2236个现有／历史站名对应2231个离线Ogg音频，约25.2MB。声音来自MIT许可的MeloTTS普通话模型，预先合成，不模仿运营方播音员，不分发模型或Python环境。播放沿真实展示路径读下一站，限频、不排长队，暂停和关闭展示立即停止。字典及显式读音规则已检查，**未进行全部音频的人工听审**。

发行包需保留media目录，包含固定版本的独立FFmpeg／ffprobe组件、LGPL及GPL补充条款、来源与校验记录。无需玩家自行安装。程序、组件、ZIP和校验说明作为一组替换，失败时回滚。

## 验证与边界

已执行的新规则、正式建设后只读展示、五城全网示意图、原生窗口矩阵、视频导出和故障检查见实施记录。五城完整重放、本轮性能与候选程序检查以同版本验证报告为准，未完成前不宣称通过。

本轮没有把旧有内容审计改写成通过。现有五城配置包含上海37、北京32、广州35、深圳27、成都39个历史节点，另登记60条规划篇记录；配置数量不代表全史准确。2026-10-31重新运行独立资格查询，仍有11类未通过：上海4、北京4、广州1、成都2，深圳通过；不是简单地只缺11个站。部分长线中间分期开通仍未完整拆分。不能以收藏和小游戏代替这些内容工作。

真人新手观察、干净Windows兼容性需要外部条件；未取得时不冒充通过。详细结果见test-record、gameplay-verification-0.27.0.json、performance-0.27.0.json及本轮实施记录。
