# 存档格式19迁移说明

默认仍使用 `%APPDATA%\MetroAtlas`，测试用绝对 `--data-dir` 隔离。载入、导入、继续与备份恢复共用同一入口。

## 从格式18载入

1. 原始结构通过检查后，将原文保存到 `originals/v18_<内容SHA256>.json`。备份失败则停止迁移。
2. 保留原游戏编号、全部规划、撤销历史、里程碑与历史对象绑定，不重新摆站或改线。
3. 添加地点故事已读表及教程状态。首章未完成且原引导开启时继续引导；后续章节关闭操作引导。旧版明确跳过不当成学会。
4. 地点故事最初未读，可在当前章节地图与资料页阅读。已完成历史节点不会被重新评判。
5. 成功载入后正常保存到原游戏槽；原始迁移备份不受自动历史三份上限影响。

新存档以 `storyState.tutorialStatus` 区分 active／completed／skipped，以 `storyState.beatRead` 保存稳定故事编号。全局学会记录单独存于界面偏好的 story_tutorial 节，旧通勤教程偏好不会误关新历史教程。

## 其他情况

- 更早版本继续转换为历史进度或旧路网作品；原始经营统计归档，新故事没有运行中的客流模拟。
- 未知更新版本拒绝载入；损坏文件先提供备份恢复确认，不自动退回旧进度。
- 重学操作另建首章练习游戏，结束后回到保存的原游戏；它不覆盖原城市路网。
