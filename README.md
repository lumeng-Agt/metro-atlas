# 造一座地铁 · 城市地铁故事

Windows 原生二维游戏，Godot 4.7.2 Compatibility。当前源码版本 **0.29.0 / 存档格式 25**。

玩家依照历史章节放站、铺轨、整理线路并确认历史节点；列车仅作建设成果展示，不运行客流、班次、拥挤、容量或经营模拟。

**下载**：[最新发行版](https://github.com/lumeng-Agt/metro-atlas/releases/latest) 提供 Windows 免安装压缩包，解压后双击 `造一座地铁.exe`。无需安装 Godot，也无需联网加载地图；请保留 `media` 目录，视频导出需要其中的 FFmpeg 组件。

## 本版城市：深圳

本版只发布**深圳**一座城市，共 **27 个可玩章节**：1992 年特区筹备地铁建设起，到 2026 年秋。其中 23 个是建设篇，4 个是只有史志事件的事件篇。

深圳离线地图包共 **17 条线路关系**、**364 个站点**，全部能在至少一个建设目标中找到引用，没有从未被任何可玩章节涉及的站点。另登记 **14 条规划篇记录**：10 项在建、2 项已批、1 项线网规划、1 项官方规划。

北京、上海、广州、成都四城的数据仍保留在 `data/` 中，供目录校验、历史回放和已有存档使用，但**不作为新游戏入口**。它们的内容尚未达到本版的发布标准。

**这只是地图线路目标覆盖，不代表从早期历史到 2026 年已完整分期复原。** 部分长线线路的中间分期开通尚未拆成独立任务。站间线形为现代地图近似走廊，不是地下工程测绘。资料只到走廊时不会伪造精确站位；离线地图快照为现代地理参考，不能单独证明历史开通事实。详细清单见[五城覆盖与资料清单](docs/network-coverage-2026-10-01.md)。

## 建设操作

1. 进入当前里程碑，左栏显示年代、章节进度和本章建设任务；多线路章节可逐条切换。
2. 点击下方「车站」，再点击当前任务的目标站区放置预览；调整朝向后，在右侧确认。
3. 点击「铺轨」，连接本任务相邻车站的站端；检查走向后确认。连续复现可批量预览多个相邻区间，并整体撤销。
4. 通过本章检查后确认历史节点。换乘站需要分别建设线路站体，再明确建立站体间换乘联系；换乘联系不属于列车轨道。

部分章节以**规划提案**开场：先在正式施工前排布公共站点，方案按历史记录评分，再进入建设。

拖动空地平移，滚轮缩放；点击车站或轨道打开详情。R 旋转，Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做；Esc 或右键先取消本步。确认历史里程碑后建立撤销边界，旧章节复盘使用独立副本。

## 存档

- 每局只有一个自动进度槽；每 300 秒检查一次，有持久修改才覆盖。视角平移和缩放不单独标记为未保存。
- 手动保存、确认历史节点及离开游戏会立即保存到同一槽。旧版时间戳自动历史仍可在存档中心删除；新版不再新增自动历史文件。
- 「当前进度另存为…」保存副本，不是开始新游戏。命名存档可搜索、改名、覆盖及删除。
- 迁移前保留原始存档备份，不自动移动站轨或推断新增历史任务已完成。未知新格式拒绝加载。
- 默认文件位于 `%APPDATA%/MetroAtlas`。开发测试使用绝对目录参数 `-- --data-dir=D:/...`。

## 界面

主菜单与工作台使用脱离边缘的浮动卡片：圆角、投影、明确边界。菜单高度按内容计算，并随窗口高度限制条目缩放，1366×768 到 1920×1080 与 100%–175% 缩放均不溢出。

## 工程与验证

Godot 打开 `project.godot` 即可运行。主入口为 `scripts/story_app.gd`，章节评估为 `scripts/story_session.gd`。发布城市由 `scripts/world_data.gd` 的 `PUBLISHED_CITY_IDS` 决定。

验证结果：

- 游戏验证 **39/39** 通过（`docs/gameplay-verification-0.29.0.json`）
- 布局检查 **267 项**通过，覆盖 1366×768、1600×980、1920×1080 与 100%／125%／150%／175%
- 持续集成工作流通过

测试结果及未执行项目见[测试记录](docs/test-record.md)。性能未测：本版改动为界面布局与提案系统，`docs/performance-0.29.0.json` 状态为 `not_run`，不引用旧版本短测数据。

**界面截图**：`tools/capture-ui.ps1` 可把应用驱动到指定场景并渲染成 PNG，用于检查实际渲染结果而非仅阅读布局代码。用法见 [tools/UI-CAPTURE.md](tools/UI-CAPTURE.md)。

发行目录只保留固定名称的 EXE 和一个 Windows ZIP。地图数据和字体许可见 `THIRD_PARTY_NOTICES.txt`；离线地图无需联网瓦片。
