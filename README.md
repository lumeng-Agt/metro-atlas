# 造一座地铁 · 城市地铁故事

Windows 原生二维游戏，Godot 4.7.2 Compatibility。当前源码版本 **0.25.0 / 存档格式25**。本版将早期样章接入五城里程碑建设任务，并修复旧档停在“资料边界”后无法继续的问题。

玩家依照历史章节放站、铺轨、整理线路并确认历史节点；列车仅作建设成果展示，不运行客流、班次、拥挤、容量或经营模拟。

## 五城章节

当前目录共120个时间轴节点：上海22、北京25、广州25、深圳27、成都21；其中101个节点包含铺轨目标。五城95条离线地图线路关系均能在至少一个建设目标中找到引用，每城末尾设有截止日全网核对节点。**这只是地图线路目标覆盖，不代表从早期历史到2026年已完整分期复原。**旧存档保留现有路网与已完成章节，停在旧“历史缺口”的存档会从最早缺少的稳定章节编号继续。

本版覆盖的是五城离线地图包中的95条线路关系和其截止日站点目标。北京官方“30条”与本地24条地图关系使用不同统计口径；此数字不表示它们是一一相同的线路单位。最终网络目标已进入任务，但历史施工事件目前主要按线路达到当前范围的公开开通节点组织，不能把每一站的逐期施工年月都视为已重建。站间线形为现代地图近似走廊，不是地下工程测绘。

**在建和批准项目只有 6 项做成了可玩的建设篇，其余仍未完成。** 已可玩：广州12号线中段、广州13号线二期西段、上海23号线一期、上海15号线南延伸、深圳17号线一期、成都18号线三期北延段。只有政策或线网规划表述的 4 项已标为可选，北京亦庄线联络工程按“不新增车站的工程条目”单列，两类都不再阻塞自由创作；其余在建项目和公开来源保留在[五城覆盖与资料清单](docs/network-coverage-2026-10-01.md)。资料只到走廊时不会伪造精确站位；离线地图快照为现代地理参考，不能单独证明历史开通事实。

## 建设操作

1. 选择城市后进入当前里程碑，左栏显示年代、章节进度和本章建设任务；多线路章节可逐条切换。
2. 点击下方“车站”，再点击当前任务的目标站区放置预览；调整朝向后，在右侧确认。
3. 点击“铺轨”，连接本任务相邻车站的站端；检查走向后确认。连续复现可批量预览多个相邻区间，并整体撤销。
4. 通过本章检查后确认历史节点。换乘站需要分别建设线路站体，再明确建立站体间换乘联系；换乘联系不属于列车轨道。

拖动空地平移，滚轮缩放；点击车站或轨道打开详情。R旋转，Ctrl+Z撤销，Ctrl+Shift+Z / Ctrl+Y重做；Esc或右键先取消本步。确认历史里程碑后建立撤销边界，旧章节复盘使用独立副本。

## 存档

- 每局只有一个自动进度槽；每300秒检查一次，有持久修改才覆盖。视角平移和缩放不单独标记为未保存。
- 手动保存、确认历史节点及离开游戏会立即保存到同一槽。旧版时间戳自动历史仍可在存档中心删除；新版不再新增自动历史文件。
- “当前进度另存为…”保存副本，不是开始新游戏。命名存档可搜索、改名、覆盖及删除。
- 迁移前保留原始存档备份，不自动移动站轨或推断新增历史任务已完成。未知新格式拒绝加载。
- 默认文件位于 `%APPDATA%/MetroAtlas`。开发测试使用绝对目录参数 `-- --data-dir=D:/...`。
