# 造一座地铁 · 城市地铁故事

Windows 原生二维游戏，Godot 4.7.2 Compatibility；当前源码为 **0.18.0 / 存档18**。双击 [造一座地铁.exe](release/造一座地铁.exe) 运行，不需要浏览器、本地网页服务或联网地图。

玩家依照有来源的历史目标亲手放站、铺轨，经历方案修改，检查站序与连接，确认历史节点后观看线路亮起与列车展示。历史年代只由章节推进。没有需求生成、乘客、拥挤、班次、容量或经营指标；列车展示暂停与否不影响通关。

## 当前可玩范围

五城首批故事共13章：上海4、北京4、广州2、深圳1、成都2。上海包括1996年分段试运营及1997年线路贯通整理；深圳首章可对比1998、2000、2002年的一期范围，再确认2004年实际开通范围。上海从1号线南段开始，继续到全线和莘庄贯通。故事资料、位置精度与缺口见 [覆盖审计](docs/campaign-content-audit.md)。

**这不是五城全史完成版。** 截至2026-10-01的全部现状线路、其余历史变更及官方远期蓝图尚未完整核验。完成已有故事会停在资料边界，不假装完成全史，也不提前解锁自由创作。现代道路和建筑只是地理参考；蓝色站区间虚线是示意，不是工程中心线。

## 操作

1. 选择城市，默认勾选首章逐步引导，点击“开始城市故事”。读完开场，展开蓝图。
2. 引导指向下方真实“站点”按钮；点击目标站区放置预览，再点右侧“确认车站”。先学习两站，再展开后续目标。
3. 点击“轨道”，依次选择两座站的接轨端，检查预览，确认轨道段。可从节点连续铺到空地；自由端点会标“待连接”。
4. 在“城市故事”页检查本章。缺站、错站区、断轨或不正确的中间站进出端会给出定位提示。“核对区间走向”可以选择相邻站之间的候选路径。
5. 符合条件后明确确认历史节点，生成本期线路及开通展示；不再手动安排运营、班次或等待乘客到达。
6. 学会两站接轨后可辅助完成重复建设。辅助先预览，确认后整体撤销；不覆盖冲突建设、不自动确认历史节点。

拖动空地平移，滚轮缩放；点击车站或轨道打开详情。R旋转15°，详情也可输入任意角度。Ctrl+Z撤销，Ctrl+Shift+Z / Ctrl+Y重做。Esc或右键先取消本步，再退出工具。空格仅暂停展示列车。确认历史里程碑后建立撤销边界；复盘时间轴里的旧章节会另建副本。

## 存档

- 自动进度按独立游戏编号隔离，同城可以有多个故事；确认建设后保存，未保存状态定时保存。
- 每局最多保留3份自动历史，只有内容变化的定时保存才轮换。存档中心可载入或单独删除历史。
- “当前进度另存为…”保存副本，不是开始新游戏。命名存档可搜索、改名、覆盖及删除。当前使用的自动进度需先回主菜单才能删除。
- 旧版存档导入前保存原始内容备份。自由规划及现实路网存档变为“旧路网作品”，原客流只归档，不继续计算。旧历史原件可恢复；未安全转换的撤销不混用。
- 损坏恢复先询问，写出独立副本成功后才能载入；保存失败保留当前会话。
- 默认文件位于 `%APPDATA%/MetroAtlas`。开发测试统一使用绝对目录参数 `-- --data-dir=D:/...`；无效参数停止读写。

## 工程与验收

Godot打开 `project.godot` 即可运行。新运行入口为 `scripts/story_app.gd`，故事评估为 `story_session.gd`，几何建设为 `story_construction.gd`。原经营模拟脚本已移除。

自动回归覆盖章节检查、显式历史身份、撤销、几何、隔离保存、旧档迁移、五次独立进程续玩及三档窗口/四档缩放。原生鼠标操作与未完成项目另见 [本轮测试记录](docs/test-record.md)。自动布局不替代真人观察；当前完整历史与远期内容未验收。

发行仅保留固定名称的EXE与一个Windows ZIP；构建提交和资源清单在 `release/build-info.txt`。地图数据和字体许可见 `THIRD_PARTY_NOTICES.txt`；五城离线地图分块可校验，不请求公共瓦片。
