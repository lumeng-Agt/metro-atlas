# 造一座地铁：原生桌面版

这是一个 Windows 原生 2D 桌面游戏，不需要浏览器、Node.js 或本地网页服务。当前源码构建为 **0.17.0 · 2026.10.17**，本地存档格式为 **17**。工程位于本目录；Windows 免安装包和独立程序会导出到 `release/`。

使用 Godot 4.7.2 打开 `project.godot` 可从源码运行。玩家解压发行包后，直接双击 `造一座地铁.exe`。

## 城市历史复现

新游戏从选择城市进入历史建设章节。五城各自保存进度；章节按建设、方案变更和开通节点推进，年份与日常模拟时钟分开。新手引导会逐次高亮下方真实工具栏、地图目标和确认按钮，不会替玩家建造。

当前资料包属于**首批可玩样板**，不是五城全史复原版：上海覆盖1号线早期建设与莘庄延伸，北京覆盖一期与苹果园延伸及向公众开放，广州覆盖1号线先行段和贯通，深圳覆盖2004年一期十字网络，成都覆盖1号线首期开通与南延伸。任务页逐城列出尚未整理的历史范围和官方来源；站区容差是游戏参数，蓝色虚线是站区间示意，不是工程测绘线位。

当前逐城章节数、事件数、远期资料状态和未完成范围见[历史内容覆盖审计](docs/campaign-content-audit.md)。

完成样板章节后，游戏会展示各城官方远期规划来源。目前远期资料还没有逐线数字化、审核的蓝图，所以不能宣称已复现远期网络，也不会以“读过文件”代替完成建设来解锁自由阶段。完整历史、远期蓝图和自由扩建解锁仍是未完成工作。

旧版“从零规划”与“扩建现实路网”存档不会被清除，可以从存档中心载入；它们不计作历史章节完成。

历史章节仍使用下列建设工具：**放置车站 → 铺设物理轨道 → 创建运营线路**。车站自带双向站台轨道；线路按停靠顺序选择车站，并将经由轨道与方向保存在存档中。

## 现实规划思路与分期

- 章节给出明确的起终点和主要出行方向。站址预览显示覆盖、与邻站覆盖重叠及完整旅程估算；站间距影响覆盖和运行表现，但不会单独阻止开通。
- 结果分开看覆盖、完整出行时间、等待与拥挤、换乘负担。预计旅程与实际批次记录明确区分；没有实际到达样本时不会显示虚构成绩。
- 任务页允许给当前建设阶段指定最多三组稳定编号的出行。阶段记录包含车站、轨道、线路和未开通区间，并显示指定需求是由本阶段接通、其他阶段已有服务，还是尚未接通。
- 车站可标记为“拟换乘站”来比较未来走廊。标记只是规划意向；只有两条已开通线路停靠同一车站并完成真实跨线出行，才形成有效换乘。
- 五城分别提供住宅入住、就业增长和定期活动。任务页提前显示地点、时间和影响方向；客流变化幅度为游戏设定，日程固定并保存在本地进度中。
- 城市事件只增加涉及事件地点的需求组。成果对照要求同一日内时段、完整统计桶和相同事件状态；条件不足时显示样本不可比，不把自然客流变化归因于改造。
- 地面接驳依据直线距离估算。本地地图不能证明过街、河流通行或施工可行性，相关资料仍标为待核验。

## 建设操作

- 拖动空白地图平移，滚轮缩放；左键点击对象查看详情。
- “放置车站”后点地图设置中心，拖动调整位置，按 `R` 每次旋转 15°，确认后站台两端出现 A／B 接轨节点。右侧车站详情可改名、换车型、调地下深度、从端点铺轨或拆除；点击站体内部即可选中。移站、转向、调深度和车型时会检查站体与相邻轨道，冲突时保留原方案。
- “直线铺轨”：选择起点，再选终点，查看预览后点“确认轨道段”。终点可以是站端、已有轨道端点、轨道中段或空地。接入轨道中段会拆分原区间并保留其线路连接。
- “曲线铺轨”：依次选择起点、弯曲控制位置和终点，再确认。确认后的曲线可以选中，进入“调整曲线控制点”拖动手柄。
- “连续铺设”可在自由端点继续画下一段；接到车站后当前铺轨操作结束。底部始终有“结束铺轨”。`Esc` 或右键先取消当前预览，再退出工具；已确认的区间使用撤销恢复。
- 地下深度范围为 5–60 米，工具栏按钮每次调整 5 米。地下深度是相对游戏参考地面的预设；超过 35‰ 的坡段和同层未接轨交叉会阻止确认，300 米曲线半径是提示值。
- “创建运营线路”时按站序点选车站。物理轨道不属于某条运营线路；可由多条线路共用。拆除运营线路不会拆掉轨道。
- 在线路详情可从起点或终点继续扩建。原停站顺序和已确认走向会保留；新增停站走向确认后整条线路暂停，检查并重新开通后才恢复服务。取消不会动原线路。
- 如果已运营线路的某段轨道被拆除，线路会暂停并保留“待接通”区间。在线路详情点“修复”，选择新铺轨后的候选走向并确认，再检查开通；其他区间与停站顺序会保留。
- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；Mac 使用 `Command`。`Esc` 取消操作，空格暂停／继续。
- 顶部集中城市、游戏时间、暂停速度、撤销重做、保存状态与菜单；窗口失焦时自动暂停。主菜单“设置”提供 100%、125%、150%、175% 四档界面缩放，也可关闭短暂淡入动效。
- 底部保留选择、车站、轨道、运营线路和更多工具；直／曲线、深度、连续铺设和候选走向随当前工具移入右侧建设详情。
- 左侧分为“线路、任务、统计”三页；统计页可直接查看等待、在途、到达、放弃与中断人数及定义，并查看近一小时按线路方向统计的载客率、峰值载客和空载区间比例。样本不足时会明确显示。规划或模拟推进后会显示“未保存”，保存失败时可点按重试。退出、回菜单或切换城市前会检查保存结果；损坏存档不会被空白开局自动覆盖。
- 新游戏现在从城市历史章节开始；旧版空白规划与街区挑战存档仍可在存档中心载入，不会被历史模式覆盖。
- 线路支持“全天统一／分时段”班距。分时段默认早高峰 07:00—10:00、晚高峰 16:00—19:00、其余为平峰；更改只安排后续班次，不重排已经发出的列车。
- 地图分析可切换规划、需求、可达性和运营问题。可达性按完整旅程时间分组，站外接驳仍是直线估算；运营问题显示模型识别的拥挤方向和区间。
- 统计页保留最近七个游戏日的 15 分钟客流桶及最多 1,000 条确定性抽样的实际旅程事件，可查看乘车、到站及到达位置。抽样只用于回看，不改变客流。
- “规划复杂度”列出总里程、最深深度、曲线区间和换乘站数量，作为方案比较信息，不是工程评分。

## 地图与资料

历史章节明确使用现代地理参考底图。蓝图容差和虚线走廊用于辅助复现公开站区/走廊，不代表旧时道路、工程测绘或地下隧道位置。

- 五城地图数据随游戏离线提供，使用 OpenStreetMap / Geofabrik 矢量数据制作，发行包不依赖地图服务，也不会请求在线瓦片。
- 城市总览显示快速路与干道、水系、绿地和少量地名；放大到城区后显示城市主路、次要道路、主要公共建筑轮廓和路名，建站尺度再显示淡色普通建筑轮廓。地图不会绘制餐馆、商店、公交站等底图图标；游戏需求地点使用独立标记。
- 本地地图包约 68 MB（压缩），边界按现有站点及需求点向外扩约 10 公里。数据来源、日期、范围、原始文件哈希与分块校验值见 `data/basemap/manifest.json`。
- 需要署名：© OpenStreetMap contributors。派生地图数据依 ODbL 1.0 授权；许可信息见 `data/basemap/README.txt` 和 `THIRD_PARTY_NOTICES.txt`。
- 底图只是视觉参照，不代表已取得步行路网、地籍、实测建筑或工程地质资料。地图边界之外仍可放站和铺轨，会显示网格与范围提示。
- 现实路网快照日期为 2026-10-05。已有区间可能是站间示意，不代表实测轨道曲线；需求和客流数值属于游戏设定。
- 车型参数、来源链接和日期见 `data/vehicles.json` 及游戏内车型详情。车站长度随所选列车总长，站体和地下深度均为游戏规划表达，不是工程标准。

## 运行与模拟边界

线路检查、线路路径、列车位置和乘客运行时间从同一份实体轨道数据计算。每列模拟列车保存方向、发车时刻和逐站到发时刻；模拟使用累计游戏秒处理到站、下车、换乘、上车和发车。乘客按批次搭乘具体列车，只占用当前区间容量，到站后再转入下一段；容量不足时继续排队，等待超过 30 游戏分钟会记为放弃。调整班次只影响之后安排的新列车，不改写已经发出的列车。只有到达目的地的批次计入完成出行。

起终点会比较 800 米范围内的车站及估算总耗时；站外步行和同站换乘使用明确标注的游戏估算。共用同一车站对象的线路可以换乘；地图上的几何交叉和相邻站体不会自动连通。站间距影响运行时间和需求覆盖，不作为开通门槛。车辆默认自动保障。

本版不包含可编辑的站厅室内、出口通道、车辆段、车辆采购、逐列信号调度、完整步行网络或工程规范校核。缺少资料的现实线路会保留待核验提示，不伪装成实测方案。

## 本地存档与迁移

存档格式为 **17**，位于 `%APPDATA%\MetroAtlas\saves`；最近进度在 `%APPDATA%\MetroAtlas\last_game.json`。写入前保留 `.bak`。版本 16 及更早存档迁移前保留独立原始备份；旧版自由规划与既有网络继续保留，历史复现进度按独立模式保存。章节进度、阶段目标和事件状态随本地存档保存。

每座城市和开局分别保存自动存档。默认每 **5 分钟现实时间**自动保存一次未保存的进度；每个城市和开局最多保留最近三份有效自动历史，可在存档中心查看时间并确认载入。也可在“设置 → 自动存档”关闭定时保存，或改为每 2、10、15 分钟。建设确认、暂停、失焦及退出时仍会即时保存。顶部保存状态可查看失败原因并重试。

命名存档可以保留多个独立进度。主菜单和游戏内统一从“存档中心”按自动或命名分页浏览；可搜索、改名、确认覆盖或删除手动副本，并查看命名存档与自动历史占用空间。手动副本不会被自动存档覆盖。载入前会先保存当前进度，载入后默认暂停，并更新该城市对应的自动存档。手动存档文件位于 `%APPDATA%\MetroAtlas\manual_saves`，可从存档中心打开文件夹管理空间。

操作历史各自保留最近 200 步；撤销规划不会倒退游戏时钟或抹去已完成出行。顶部“存档”菜单也可导入或导出 JSON，旧网页存档需先在网页端导出。
