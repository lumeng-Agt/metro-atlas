# 造一座地铁 · 城市地铁故事

Windows 原生二维游戏，Godot 4.7.2 Compatibility。当前源码版本 **0.29.0 / 存档格式 25**。

玩家依照历史章节放站、铺轨、整理线路并确认历史节点；列车仅作建设成果展示，不运行客流、班次、拥挤、容量或经营模拟。

**下载**：[最新发行版](https://github.com/lumeng-Agt/metro-atlas/releases/latest) 提供 Windows 免安装压缩包，解压后双击 `造一座地铁.exe`。无需安装 Godot，也无需联网加载地图；请保留 `media` 目录，视频导出需要其中的 FFmpeg 组件。

## 五城章节

当前共 **170 个可玩章节**：上海 37、北京 32、广州 35、深圳 27、成都 39。其中 150 个是建设篇，19 个是只有史志事件的事件篇。另有 **60 条规划篇记录**登记在建与已批项目。

五城离线地图包共 **96 条线路关系**，全部能在至少一个建设目标中找到引用，没有从未被任何可玩章节涉及的站点。每城末尾设有截止日全网核对节点。

**这只是地图线路目标覆盖，不代表从早期历史到 2026 年已完整分期复原。** 部分长线线路的中间分期开通尚未拆成独立任务。北京官方「30 条」与本地 25 条地图关系使用不同统计口径，不表示一一相同的线路单位。站间线形为现代地图近似走廊，不是地下工程测绘。

资料只到走廊时不会伪造精确站位；离线地图快照为现代地理参考，不能单独证明历史开通事实。详细清单见[五城覆盖与资料清单](docs/network-coverage-2026-10-01.md)。

## 建设操作

1. 选择城市后进入当前里程碑，左栏显示年代、章节进度和本章建设任务；多线路章节可逐条切换。
2. 点击下方「车站」，再点击当前任务的目标站区放置预览；调整朝向后，在右侧确认。
3. 点击「铺轨」，连接本任务相邻车站的站端；检查走向后确认。连续复现可批量预览多个相邻区间，并整体撤销。
4. 通过本章检查后确认历史节点。换乘站需要分别建设线路站体，再明确建立站体间换乘联系；换乘联系不属于列车轨道。

部分章节以**规划提案**开场：先在正式施工前排布公共站点，方案按历史记录评分，再进入建设。

拖动空地平移，滚轮缩放；点击车站或轨道打开详情。R 旋转，Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做；Esc 或右键先取消本步。确认历史里程碑后建立撤销边界，旧章节复盘使用独立副本。

## 存档

- 每局只有一个自动进度槽；每 300 秒检查一次，有持久修改才覆盖。视角平移和缩放不单独标记为未保存。
- 手动保存、确认历史节点及离开游戏会立即保存到同一槽。旧版时间戳自动历史仍可在存档中心删除；新版不再新增自动历史文件。
- 「当前进度另存为…」保存副本，不是开始新游戏。命名存档可搜索、改名、覆盖及删除。
- 迁移前保留原始存档备份，不自动移动站轨或推断新增历史任务已完成。未知新格式拒绝加载。
- 默认文件位于 `%APPDATA%/MetroAtlas`。开发测试使用绝对目录参数 `-- --data-dir=D:/...`。

## 界面

主菜单与工作台使用脱离边缘的浮动卡片：圆角、投影、明确边界。菜单高度按内容计算，并随窗口高度限制条目缩放，1366×768 到 1920×1080 与 100%–175% 缩放均不溢出。
