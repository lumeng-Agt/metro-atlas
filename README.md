# 造一座地铁：原生桌面版

这是一个 Windows 原生 2D 可玩样版。游戏直接运行在 Godot 桌面窗口中，不需要浏览器、Node.js 或本地网页服务器。旧网页版本及其数据没有被覆盖。本仓库提供完整工程和资源；本机导出的 `.exe` 与 `.zip` 安装包不纳入 Git 历史。

若要打开工程继续修改或从源码运行，请使用 Godot 4.7.2，打开本目录的 `project.godot`，等待资源导入完成后按 F6/F5 运行。导出 Windows 版本需要安装对应的 Godot 导出模板。

## 开始游戏

1. 如果你下载的是 Windows 发行包，解压后双击 `造一座地铁.exe`；源码仓库本身不包含导出包。
2. 选择城市和“从零规划”或“扩建现实路网”。新开局默认暂停。
3. 首次从零规划会从一片街区的 A→B 出行需求开始；只显示这组地点，并提示先后建设两站、连接端点、检查开通，再观察真实模拟服务。引导可以跳过、查看全城或之后重玩。扩建现实路网开局改为浏览现有线路提示。
4. 按引导在底部点“建车站”，在 A、B 附近各确认一站；随后点“连接轨道”，依次选两站端点。
5. 点“检查并开通线路”，再按顶部播放键。完成条件按这组需求是否实际获得模拟服务判断；没有逐人乘车动画时会明确显示估算结果。

## 操作

- 鼠标左键拖空白地图：平移；滚轮：缩放。
- “选择”：点车站、轨道或需求地点查看详情；拖动车站可移动。
- “建车站”：选择当前线路，点地图出现预览；可以拖动或重新点空地换位置，按 `R` 每次转向 15°，再确认或取消。
- “连接轨道”：先点一站的 A／B 端，再点另一站端点。接轨完成自动回到选择工具；也可在车站详情用“从本站接轨”。
- “调曲线”：点轨道选中区间，再拖动蓝色控制点。
- “拆除”：点车站或轨道删除；删除车站时相邻轨道一并移除。线路管理在左侧线路卡片中。
- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；Mac 使用 `Command`。
- `Esc` 取消当前预览或操作；空格暂停／继续。
- 顶部支持暂停、1×／3×／10×。窗口失焦时自动暂停。
- 地图右上角切换站体、需求与线路图层；顶部“线路”和“详情”按钮可收起侧栏。
- 主菜单的“设置”提供 100%、125%、150%、175% 四档界面缩放；地图镜头缩放独立保存。放大界面或缩窄窗口时，侧栏会自动收起。

开局页采用居中的双栏规划工作台，重要操作使用大按钮；常用正文默认 18px，辅助文字至少 15px。屏幕较矮时菜单会压缩说明并保留主要按钮。样例见 `docs/menu-preview.png`、`docs/menu-preview-1366x768.png`；游戏内界面见 `docs/ui-preview-1600x980.png`、`docs/ui-preview-1366x768.png`。

车站名称、移动、旋转和删除集中在右侧“车站详情”；轨道可直接点选后查看长度、预计运行时间并删除。接轨时端点会高亮并显示 A／B 标识，需求点不会抢走端点点击。

## 游戏内容与资料范围

- 上海、北京、广州、深圳、成都各有从零规划和扩建现实路网两种独立开局。
- 车站为按真实地图比例绘制的矩形简化站体，长度跟随列车编组并内置双向轨道；长度是游戏布局表达，不是实测建筑尺寸。
- 可选车型来自附带的代表性车型资料；参数按来源标记。游戏中的运能和客流均是模拟设定，不是现实运营预测。
- 现实路网使用 2026-10-05 的站点与线路站序快照；旧线路以虚线表示站间示意，不代表实测轨道曲线。规划需求点及人次也以游戏设定为准。
- 在线底图使用 OpenStreetMap 标准地图瓦片，只按视野请求并遵循服务器缓存响应；已有瓦片会保存在本机，断网时仍可规划和存档。OSM 图片只用作底图，未把图片当成道路或建筑数据。
- 首次教学地点使用带 OSM 来源链接的具体住宅区、学校、就业地点或枢纽；客流量仍是游戏设定。清爽规划只淡化地图图片并暂时隐藏其他需求标记，未缓存或拒绝访问时仍可在定位网格上规划。
- 线路距离影响估算运行时间，但不设开通站间距门槛。车辆默认自动保障。此版尚未加入玩家自建车辆段、列车采购、完整换乘与共轨调度、A/B 试运行、逐人乘客动画或工程规范校核。

## 存档、迁移与恢复

存档位于 `%APPDATA%\MetroAtlas\saves`，最近一次游戏状态位于 `%APPDATA%\MetroAtlas\last_game.json`。每次替换保存会保留一个 `.bak` 备份。顶部“存档”菜单可导入或导出 JSON；旧网页存档请先在网页版本导出，再于桌面版导入。切换城市或开局不会共用规划数据。

操作历史按城市和开局保存最近 200 步。运行时间、已完成出行不随规划撤销回退。
